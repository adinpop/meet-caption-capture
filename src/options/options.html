OpenAI API key

Used for Whisper audio transcription. Stored only on this device via chrome.storage.local. Never synced to your Google account, never sent anywhere other than api.openai.com. The key lives in plaintext in your Chrome profile directory, so your OS user account is the trust boundary.

Recommended: create a restricted key scoped to the Audio API only, with a hard usage limit on your OpenAI account.

Summary sections

After a meeting, click Summarize in the popup to have the transcript analyzed by gpt-4o-mini (or a model you pick below) and merged into the same Markdown file. Sent to api.openai.com/v1/chat/completions with your key.

{{transcript}} is replaced with the joined captions + Whisper text at call time. The model is told to return a JSON object with keys matching the sections above.

How it works

  • Audio is captured from the active Meet or Teams tab only while you click Record audio in the popup.
  • Audio is chunked into 30 second segments and uploaded to api.openai.com/v1/audio/transcriptions as they become available.
  • Raw audio is held in IndexedDB while in flight and deleted after successful transcription.
  • Transcripts are merged into the downloadable Markdown file under a separate ## Audio transcript section.
  • Summaries (optional) prepend ## Summary, ## Topics discussed, ## Decisions, ## Action items, ## Blind spots, ## Opportunities sections above the transcripts. Original transcripts are never modified.
